# Limitations of the Analysis

Here I list the limitations of both the dataset and the analysis. What can/can't this study reveal.

---

Spillover interference likely: one game being discounted likely affects outcome of another game. Violates no-interference assumption. Depending on the analysis carried out, a treated game's discount pulls players from comparison games, so those controls are contaminated and DiD will overstate the effect.

Selection bias: We consider only the top-played games. This analysis is likely not generalizable to the entire Steam catalogue.

External events: This is an unobserved confounder that could heavily impact the treatments/controls, and the analysis as a whole. 

DLC/Game Updates: Influence from developer support of a game is not handled in this analysis. Information on game updates is not available in this dataset, so correlation analysis with the outcome is beyond the scope of this study.
